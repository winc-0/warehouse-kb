# FG-3 流利式货架使用手册

> 编号：FG-3　|　厂商：音飞储存　|　类别：存储设备

> 适用范围：区域仓拆零拣货区　|　版本：V1.4　|　归口：北京优速通供应链管理有限公司 运营中心

## 1 概述

FG-3 靠滚轮坡度让周转箱自己滑到拣货面，后端补货、前端拣货，天然 FIFO。滚轮标准倾角 3 度，可调 2~5 度——倾角太小箱子滑不动，太大则末端冲击会把箱子撞翻，所以**中段必须装减速滚轮**。它只接受底面平整的塑料周转箱（标准 600×400），纸箱底面软且有毛刺，会卡在滚轮之间，属于不适用件型。

## 3 标准作业流程

1. 安装后逐道试滑：空箱从后端放入，确认能滑到前端且不冲出。
2. 补货从后端放入，不得从前端塞入（会破坏 FIFO）。
3. 每组中间装减速滚轮，末端装挡板。
4. 单箱重量不超过 35 kg，超重箱改走横梁货架。
5. 每班检查滚轮有无卡滞与异响。
6. 拣货面取箱后及时补货，避免空道。

## 4 常见故障与处理

| 故障现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 箱子滑不到前端 | 倾角小于 2 度或滚轮卡滞 | 把倾角调至 3 度并清理滚轮异物 |
| 末端箱子被撞翻 | 未装减速滚轮或倾角大于 5 度 | 加装减速滚轮并把倾角回调至 3 度 |
| 纸箱卡在滚轮间 | 件型不适用 | 改用塑料周转箱，纸箱不得上流利架 |
| 滚轮异响 | 轴承缺油或进异物 | 清理并补加润滑脂 |
| 箱子卡在中段 | 减速滚轮磨损或倾角不足 | 更换减速滚轮并复核倾角 |
| 滚轮转动不灵 | 轴承进异物或缺油 | 清理并补加润滑脂 |

## 6 安全注意事项

- 纸箱禁止上流利式货架，只接受底面平整的塑料周转箱。
- 单箱不得超过 35 kg。
- 严禁从前端补货，会破坏 FIFO 顺序。
- 倾角不得大于 5 度，否则末端冲击会撞翻箱子。
- 纸箱禁止上流利式货架，只接受底面平整的塑料周转箱。

## 7 现场核查清单

交接班与开机前逐项确认，任一项不满足不得投入作业：

- [ ] 滚轮倾角保持 3 度（可调范围 2~5 度）。
- [ ] 中段减速滚轮完好，末端挡板牢固。
- [ ] 空箱试滑：能滑到前端且不冲出。
- [ ] 单箱重量不超过 35 kg，全部为塑料周转箱。
- [ ] 补货从后端进行，未从前端塞入。
