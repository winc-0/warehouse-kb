# SOP-WH-04 越库（Cross-docking）作业规范

> 编号：SOP-WH-04　|　归口部门：运营中心　|　类别：作业规范

> 适用范围：促销备货、生鲜、季节性商品越库　|　版本：V1.5　|　归口：北京优速通供应链管理有限公司 运营中心

## 1 概述

越库是货到即走、不入库存储的作业方式，用来压掉上架再下架这两次搬运。适用条件是硬性的：到货后 24 小时内必须出库，且单 SKU 数量不少于 50 件。需要质检、贴标、换包装的 SKU 一律不适用越库——越库区没有质检工位，硬做会漏检。越库区面积占比建议 8%~12%，滞留时长目标是 4 小时以内。

## 3 作业流程

1. 到货预约：供应商在 WMS 中预约到货，注明是否越库。
2. 适用性判定：到货 24 小时内可出库且单 SKU 不少于 50 件；需质检、贴标、换包装的不得越库。
3. 系统标记：越库单在 WMS 中必须标记 cross_dock = 1。
4. 卸货分拨：在越库区按目的格口分拨，不入库上架。
5. 直送月台：分拨完成后直送出库月台装车。
6. 时效监控：越库件滞留时长目标 4 小时以内，超过 8 小时转正常入库。
7. 记录：逐单记录越库件数与滞留时长。
8. 指标：越库率 = 越库件数 / 总出库件数，目标不低于 15%。

## 4 异常场景与处置

| 异常场景 | 判定标准 | 处置方式 |
| --- | --- | --- |
| 越库件滞留超过 8 小时 | 下游车辆未到或分拨不及时 | 转为正常入库上架，不得继续占用越库区 |
| 需质检的 SKU 走了越库 | 适用性判定漏检 | 立即拦截并转入质检流程，已发运的走召回 |
| 越库区爆仓 | 越库量超出 8%~12% 面积承载能力 | 启动正常入库分流，并复核越库适用性判定 |
| 越库单未标记 | WMS 标记遗漏 | 补标记并纳入越库率统计，漏标造成指标失真 |
| 越库件错发流向 | 分拨格口对应关系错误 | 立即拦截并改发，复核格口映射表 |
| 越库件数统计缺失 | WMS 标记漏填 | 补标记并纳入统计，漏标会造成指标失真 |

## 5 关键指标与考核口径

| 指标 | 口径 | 目标值/频次 |
| --- | --- | --- |
| 越库率 | 越库件数/总出库件数 | 目标 ≥15%，月度统计 |
| 越库滞留时长 | 到货至出库 | 目标 ≤4 h，超过 8 h 转入库 |
| 越库区面积占比 | 越库区/总库区 | 建议 8%~12% |
| 单 SKU 越库门槛 | 件数 | 不少于 50 件 |
| 越库错发率 | 错发件数/越库件数 | 目标 ≤0.1% |
| 越库率 | 越库件数/总出库件数 | 目标 ≥15%，月度统计 |
| 越库错发率 | 错发件数/越库件数 | 目标 ≤0.1% |

## 6 执行红线

- 需质检、贴标、换包装的 SKU 不得走越库。
- 到货 24 小时内不能出库的不得走越库。
- 单 SKU 少于 50 件不得走越库。
- 越库单必须在 WMS 中标记 cross_dock = 1，漏标会造成指标失真。

## 7 现场核查清单

交接班与开机前逐项确认，任一项不满足不得投入作业：

- [ ] 越库适用性已判定：24 小时内可出库且单 SKU 不少于 50 件。
- [ ] 需质检、贴标、换包装的 SKU 已排除。
- [ ] 越库单已在 WMS 中标记 cross_dock = 1。
- [ ] 越库区面积占比在 8%~12% 之间，未爆仓。
- [ ] 分拨格口与目的流向对应正确。
- [ ] 滞留时长未超过 4 小时（超过 8 小时已转入库）。
