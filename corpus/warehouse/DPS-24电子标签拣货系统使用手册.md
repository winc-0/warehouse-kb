# DPS-24 电子标签拣货系统使用手册

> 编号：DPS-24　|　厂商：上尚科技　|　类别：信息系统与终端

> 适用范围：区域仓拆零拣货区　|　版本：V1.9　|　归口：北京优速通供应链管理有限公司 运营中心

## 1 概述

DPS-24 用电子标签替代纸质拣货单：标签亮灯并显示应拣数量，拣货员按键确认。相比纸质单，拣货效率提升 40%~60%。硬件约束很明确：单回路最多 128 个标签，通讯是 RS485、波特率 9600，每个标签的地址必须用拨码开关设定——地址重名会导致两个标签同时亮灯，这是现场最容易出现的错拣来源。总线两端必须接 120Ω 终端电阻。

| 参数项 | 数值 | 单位 |
| --- | --- | --- |
| 标签尺寸 | 2.3 | 寸（显示数量 + 库位） |
| 单回路最大标签数 | 128 | 个 |
| 通讯方式 | RS485 | — |
| 波特率 | 9600 | bps |
| 确认方式 | 按键 + LED 闪烁 | 红/绿/黄 |
| 亮度等级 | 3 | 级可调 |

| 终端电阻 | 120 | Ω |
| 效率提升 | 40~60 | %（对比纸质单） |

## 3 标准作业流程

1. 上架：确认每个货位只装一个标签，标签地址与 WMS 库位一一对应。
2. 设定地址：用拨码开关设定，设定后逐一点亮核对。
3. 拣货：按标签显示数量拣取，拣完按键确认，标签灭灯。
4. 数量不符时按「异常」键，由组长处理，不得自行改数。
5. 波次结束后核对未灭灯标签，逐一查明原因。
6. 下班前确认所有标签灭灯、回路无残留任务。

## 4 常见故障与处理

| 故障现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 标签不亮 | 拨码地址与系统配置不一致 | 核对拨码地址并在 WMS 中修正 |
| 两个标签同时亮 | 地址重名 | 重新设定其中一个标签地址，全回路排查重名 |
| 整条回路通讯中断 | 终端电阻缺失或总线断开 | 在总线两端补接 120Ω 终端电阻并检查接线 |
| 按键无响应 | 按键老化或标签供电不足 | 更换标签；测量末端电压是否低于 22V |
| 标签显示乱码 | 供电电压偏低或通讯受干扰 | 测量末端电压并远离动力线布线 |
| 部分回路无响应 | 该回路电源空开跳闸 | 复位空开并排查短路点 |

## 6 安全注意事项

- 一个货位只能装一个标签，严禁一货位多标签。
- 标签地址必须用拨码开关设定，禁止用软件临时指定。
- 拣货数量不符必须走异常处理，不得自行改数。
- 一个货位只能装一个标签，标签地址必须用拨码开关设定。

## 7 现场核查清单

交接班与开机前逐项确认，任一项不满足不得投入作业：

- [ ] 每个货位只装一个标签。
- [ ] 标签拨码地址与 WMS 库位一一对应，无重名。
- [ ] RS485 总线两端已接 120Ω 终端电阻。
- [ ] 末端电压不低于 22V。
- [ ] 波次结束后所有标签灭灯。
