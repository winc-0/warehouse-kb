# CBS-600 交叉带分拣机使用手册

> 编号：CBS-600　|　厂商：中集智能　|　类别：输送分拣设备

> 适用范围：中心仓分拣主环线　|　版本：V3.1　|　归口：北京优速通供应链管理有限公司 运营中心

## 1 概述

CBS-600 是中心仓的分拣主设备，环形轨道上布置 240 台小车，小车节距 600 mm，主线速度 2.0 m/s，处理能力 6000 件/小时。供件台扫码后由系统分配格口，小车到达目标格口时皮带横向动作把件卸出。识别失败或超界的件会被送到回收格口 R99，不会直接进入客户格口，这是保证 99.9% 分拣准确率的关键设计。

## 3 标准作业流程

1. 开机前确认环线上无遗留件，格口滑槽无堵塞。
2. 启动顺序：先开控制电源 → 启动 WCS → 点动确认 → 低速空转 3 分钟 → 提速至工作速度。
3. 供件：人工供件须把件放到小车中线，条码朝上；自动供件台按节拍上件。
4. 运行监控：盯住 R99 回收量，单小时超过 30 件必须停机排查供件与扫码环节。
5. 格口满溢：格口满溢后系统报 E21 并暂停该格口，需人工清口后复位。
6. 停机：先停供件 → 环线排空 → 降速停机 → 断控制电源。

## 4 常见故障与处理

| 故障现象 | 可能原因 | 处理方法 |
| --- | --- | --- |
| 格口满溢报警 E21 | 滑槽内件未及时清走 | 清空滑槽并在 WCS 上复位该格口 |
| 小车脱离报警 E14 | 小车与轨道连接销松脱 | 立即停机，复位小车并检查连接销，禁止带病运行 |
| 扫码成功率明显下降 | 相机镜头积灰或光源衰减 | 清洁镜头并测量光源亮度，低于初始值 70% 更换灯条 |
| 件卡在两小车之间 | 件型超出适用范围 | 停机取出，并把该件转为人工处理；检查是否超长超宽 |
| 主线速度波动 | 变频器参数漂移或皮带打滑 | 重新标定变频器并检查张紧 |
| 小车皮带跑偏 | 张紧不一致或辊筒粘料 | 调整张紧并清理辊筒 |
| 格口错分 | WCS 格口映射表未随布局更新 | 核对并更新格口映射表，做实件验证 |

## 6 安全注意事项

- 运行中严禁把手伸入环线或跨过护栏取件。
- 小车脱离（E14）必须停机处理，禁止在运转状态下复位。
- 检修时必须挂牌上锁（LOTO），并由专人保管钥匙。
- 软包、圆柱件、易滚动件不得上交叉带，必须走人工分拣区。

## 7 现场核查清单

交接班与开机前逐项确认，任一项不满足不得投入作业：

- [ ] 环线上无遗留件，格口滑槽无堵塞。
- [ ] 供件台扫码相机镜面洁净。
- [ ] R99 回收量单小时低于 30 件。
- [ ] 小车运行无异响，直线电机区域无异物。
- [ ] 急停按钮功能正常，护栏完好。
